`services`

Provided 4 services in folder services, please read and implement them in the frontend `restaurant-fe` to turn it into rbac website for restaurant management.

You need to create a UI for all the features provided by the services.

Remember , all service will not use database.

Implement pages in app folder and also in features folder.

    |
    ----[config] //zod and datatype here
    |
    ----[data-access] // api fetching functions and tanstack query call
